<task id="01.2">
<title>Create PDF generator (facture + BL)</title>
<read_first>
- apps/api/app/models/document.py (Facture, BonDeLivraison)
- apps/api/app/models/commande.py (Commande, LigneCommande)
</read_first>
<action>
Create `apps/api/app/documents/__init__.py` (empty).

Create `apps/api/app/documents/pdf_generator.py`:

Two functions:

**generate_facture_pdf(facture, commande, lignes, pharmacien) -> Path:**
- Uses reportlab canvas
- Header: "SPA DIMED PHARMA - FACTURE"
- Info: N.facture, date, client name/address
- Table: designation, qte, prix unitaire, total ligne
- Footer: montant total
- Saves to `storage/documents/factures/{reference_id}.pdf`
- Returns file path

**generate_bl_pdf(bl, commande, lignes, pharmacien) -> Path:**
- Header: "SPA DIMED PHARMA - BON DE LIVRAISON"
- Info: N.BL, date, commande reference, client
- Barcode: Code128 of bl.code_barre (using python-barcode, rendered as image)
- Table: articles list
- Saves to `storage/documents/bls/{reference_id}.pdf`
- Returns file path

Create `storage/documents/factures/.gitkeep` and `storage/documents/bls/.gitkeep`.
</action>

- `apps/api/app/documents/pdf_generator.py` contains `def generate_bl_pdf`

- `apps/api/app/documents/pdf_generator.py` contains `barcode`
- `storage/documents/factures/.gitkeep` exists
- `storage/documents/bls/.gitkeep` exists
</acceptance_criteria>
</task>

<task id="01.3">
<title>Create documents service (generate on accept + route sheets)</title>
<read_first>
- apps/api/app/documents/pdf_generator.py (created in 01.2)
- apps/api/app/models/document.py (Facture, BonDeLivraison, FeuilleDeRoute)
- apps/api/app/models/references.py (next_facture_ref, next_bl_ref)
- apps/api/app/commandes/service.py (transition_order)
</read_first>
<action>
Create `apps/api/app/documents/service.py`:

**generate_order_documents(db, commande) -> tuple[Facture, BonDeLivraison]:**
- Generate facture reference via next_facture_ref(db)
- Generate BL reference via next_bl_ref(db)
- Generate barcode string for BL (= BL reference_id)
- Create Facture record: montant_ht = montant_total, montant_ttc = montant_total (no tax v1)
- Create BonDeLivraison record with code_barre
- Insert both in DB
- Call generate_facture_pdf() and generate_bl_pdf()
- Return (facture, bl)

**create_or_get_route_sheet(db, camion_id, date) -> FeuilleDeRoute:**
- Check if active route sheet exists for this truck
- If yes, return it
- If no, create new one with empty compteurs

**assign_order_to_route(db, feuille_id, commande_id):**
- Add commande to the feuille de route (via a linking mechanism or JSONB array)
- Update compteurs

Then update `apps/api/app/commandes/service.py` `transition_order()`:
- After setting status to ACCEPTEE, call `generate_order_documents(db, commande)` to auto-generate docs.
- Import at the top of the function to avoid circular import.
</action>
<acceptance_criteria>
- `apps/api/app/documents/service.py` contains `async def generate_order_documents`
- `apps/api/app/documents/service.py` contains `next_facture_ref`
- `apps/api/app/documents/service.py` contains `next_bl_ref`
- `apps/api/app/documents/service.py` contains `generate_facture_pdf`
- `apps/api/app/documents/service.py` contains `async def create_or_get_route_sheet`
- `apps/api/app/commandes/service.py` contains `generate_order_documents` (called on accept)
</acceptance_criteria>
</task>

<task id="01.4">
<title>Create documents router</title>
<read_first>
- apps/api/app/documents/service.py (created in 01.3)
- apps/api/app/auth/dependencies.py (CurrentUser)
</read_first>
<action>
Create `apps/api/app/documents/router.py`:

**GET /documents/facture/{commande_id}** — Return facture PDF as FileResponse
- Fetch Facture by commande_id
- Check file exists on disk
- Pharmacien can only access own order's facture
- Return FileResponse with content_type="application/pdf"

**GET /documents/bl/{commande_id}** — Return BL PDF as FileResponse
- Operatrice/admin only
- Same pattern as facture

**POST /feuilles-route** — Create route sheet
- Body: {camion_id, date}
- Operatrice/admin only
- Check no duplicate active sheet for truck (RG-1-05)

**GET /feuilles-route/{id}** — Get route sheet details

**PATCH /feuilles-route/{id}/assign** — Assign orders to route sheet
- Body: {commande_ids: [uuid]}
- Operatrice/admin only

Wire into main.py:
```python
from app.documents.router import router as documents_router
app.include_router(documents_router, prefix="/documents", tags=["documents"])
```
</action>
<acceptance_criteria>
- `apps/api/app/documents/router.py` contains `@router.get("/facture/{commande_id}")`
- `apps/api/app/documents/router.py` contains `@router.get("/bl/{commande_id}")`
- `apps/api/app/documents/router.py` contains `FileResponse`
- `apps/api/app/main.py` contains `include_router(documents_router`
</acceptance_criteria>
</task>
