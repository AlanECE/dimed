# Plan 100-01: E2E API tests — pytest + httpx full coverage

## Goal

Create a comprehensive E2E test suite using pytest + httpx AsyncClient against a dedicated test PostgreSQL. Cover all M1 modules: auth, médicaments, commandes, documents, notifications, camions. Include a full happy-path flow test.

## Tasks

<task id="01" title="Add test dependencies and config">
<read_first>
- apps/api/pyproject.toml (existing deps, ruff config)
</read_first>
<action>
1. Add dev dependencies to `apps/api/pyproject.toml`:

```toml
[project.optional-dependencies]
test = [
    "pytest>=8.0",
    "pytest-anyio>=0.0.0",
    "httpx>=0.27",
    "bcrypt>=4.0",
]
```

Note: bcrypt is already a transitive dep via passlib but list explicitly for tests.

2. Create `apps/api/pytest.ini`:
```ini
[pytest]
testpaths = tests
anyio_backend = asyncio
```

3. Create `docker-compose.test.yml` at repo root:
```yaml
services:
  test-db:
    image: postgres:16
    environment:
      POSTGRES_DB: dimed_test
      POSTGRES_USER: test
      POSTGRES_PASSWORD: test
    ports:
      - "5433:5432"
    tmpfs:
      - /var/lib/postgresql/data
```
</action>

<action>
Create `apps/api/tests/__init__.py` (empty).

Create `apps/api/tests/conftest.py`:

Key fixtures:
1. `anyio_backend` — returns "asyncio" (session scope)
2. `engine` — creates async engine to `postgresql+asyncpg://test:test@localhost:5433/dimed_test`, runs `Base.metadata.create_all` at start, `drop_all` at end. Also runs `CREATE EXTENSION IF NOT EXISTS pg_trgm` for fuzzy search.
3. `db` — per-test async session from engine, yields session, rollbacks after
4. `client` — per-test `AsyncClient(transport=ASGITransport(app=app))` with `app.dependency_overrides[get_db]` pointing to test db. Clears overrides after.
5. `pharmacien` — creates test user with role PHARMACIEN via direct db insert (bcrypt hash "testpass123")
6. `operatrice` — creates test user with role OPERATRICE
7. `admin_user` — creates test user with role ADMIN
8. `login_as(client, email, password="testpass123")` — async helper that POSTs to /auth/login and returns response. Cookies auto-stored on client.
9. `sample_medicament(db)` — creates a test Medicament record (designation="Paracetamol 500mg", ppa=150.00, etc.)

Important implementation details:
- Import `app` from `app.main` and `get_db` from `app.db.session`
- Use `ASGITransport(app=app)` for httpx (required since httpx 0.24+)
- Create users with `uuid4()` id, bcrypt hashed password, `is_active=True`
- After each test, rollback the session to ensure isolation
- `engine` fixture: also execute `await conn.execute(text("CREATE EXTENSION IF NOT EXISTS pg_trgm"))` before `create_all`
</action>
