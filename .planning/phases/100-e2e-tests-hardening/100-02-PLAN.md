# Plan 100-02: Docker prod hardening — multi-stage, non-root, healthchecks

## Goal

Create production-grade Dockerfiles for API and Web with multi-stage builds, non-root user, health checks, and proper .dockerignore files. Add Next.js standalone output config. Create docker-compose.prod.yml.

## Tasks

<task id="01" title="Create API Dockerfile.prod">
<read_first>
- apps/api/pyproject.toml (dependencies, Python version)
- apps/api/app/main.py (entry point, health endpoint)
</read_first>
<action>
Create `apps/api/Dockerfile.prod`:

```dockerfile
# Stage 1: Builder
FROM python:3.12-slim AS builder

WORKDIR /build

RUN pip install --no-cache-dir uv

COPY pyproject.toml uv.lock* ./
RUN uv sync --frozen --no-dev --no-install-project 2>/dev/null || uv pip install --system -r <(uv pip compile pyproject.toml)

COPY app ./app
COPY alembic ./alembic
COPY alembic.ini ./

# Stage 2: Runtime
FROM python:3.12-slim AS runtime

RUN apt-get update \
    && apt-get install -y --no-install-recommends curl \
    && rm -rf /var/lib/apt/lists/* \
    && groupadd -r appuser \
    && useradd -r -g appuser -d /app -s /sbin/nologin appuser

WORKDIR /app

COPY --from=builder /build/.venv /app/.venv
COPY --from=builder /build/app ./app
COPY --from=builder /build/alembic ./alembic
COPY --from=builder /build/alembic.ini ./

ENV PATH="/app/.venv/bin:$PATH"

USER appuser

HEALTHCHECK --interval=30s --timeout=3s --start-period=10s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

NOTE: If uv.lock doesn't exist, fallback to pip compile. Check actual dep install method used in project and adapt the builder stage accordingly.
</action>
<acceptance_criteria>
- `apps/api/Dockerfile.prod` exists
- Uses multi-stage build (builder + runtime)
- Base image is `python:3.12-slim` (NOT alpine)
- Runtime stage creates non-root `appuser` and uses `USER appuser`
- Contains `HEALTHCHECK` with `curl -f http://localhost:8000/health`
- CMD uses exec form `["uvicorn", ...]`
- Installs `curl` in runtime for healthcheck
</acceptance_criteria>
</task>

<task id="02" title="Create Web Dockerfile.prod">
<read_first>
- apps/web/package.json (dependencies, scripts)
- apps/web/next.config.ts (current config — need to add output: "standalone")
</read_first>
<action>
1. Update `apps/web/next.config.ts` to add standalone output:
```typescript
const config: NextConfig = {
    transpilePackages: ["@dimed/shared-types", "@dimed/ui"],
    output: "standalone",
};
```

2. Create `apps/web/Dockerfile.prod`:

```dockerfile
# Stage 1: Builder
FROM node:22-slim AS builder

WORKDIR /build
RUN corepack enable pnpm

COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

COPY . .
RUN pnpm build

# Stage 2: Runtime
FROM node:22-slim AS runtime

RUN apt-get update \
    && apt-get install -y --no-install-recommends curl \
    && rm -rf /var/lib/apt/lists/* \
    && groupadd -r appuser \
    && useradd -r -g appuser -d /app -s /sbin/nologin appuser

WORKDIR /app

COPY --from=builder /build/.next/standalone ./
COPY --from=builder /build/.next/static ./.next/static
COPY --from=builder /build/public ./public

USER appuser

ENV PORT=3000 HOSTNAME="0.0.0.0"

HEALTHCHECK --interval=30s --timeout=3s --start-period=15s --retries=3 \
    CMD curl -f http://localhost:3000/ || exit 1

EXPOSE 3000

CMD ["node", "server.js"]
```
</action>
<acceptance_criteria>
- `apps/web/next.config.ts` contains `output: "standalone"`
- `apps/web/Dockerfile.prod` exists
- Uses multi-stage build (builder + runtime)
- Builder uses `node:22-slim` and `pnpm`
- Runtime creates non-root `appuser` and uses `USER appuser`
- Copies `.next/standalone`, `.next/static`, and `public`
- Contains `HEALTHCHECK`
- CMD uses exec form `["node", "server.js"]`
</acceptance_criteria>
</task>

<task id="04" title="Create docker-compose.prod.yml">
<read_first>
- apps/api/Dockerfile.prod (API Dockerfile)
- apps/web/Dockerfile.prod (Web Dockerfile)
</read_first>
<action>
Create `docker-compose.prod.yml` at repo root:

```yaml
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_DB: dimed
      POSTGRES_USER: dimed
      POSTGRES_PASSWORD: ${DB_PASSWORD:-dimed_prod}
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U dimed"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  api:
    build:
      context: apps/api
      dockerfile: Dockerfile.prod
    environment:
      DIMED_DATABASE_URL: postgresql+asyncpg://dimed:${DB_PASSWORD:-dimed_prod}@db:5432/dimed
      DIMED_REDIS_URL: redis://redis:6379/0
      DIMED_SECRET_KEY: ${SECRET_KEY:-change-me-in-production}
      DIMED_COOKIE_SECURE: "true"
      DIMED_CORS_ORIGINS: ${CORS_ORIGINS:-http://localhost:3000}
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_healthy
    ports:
      - "8000:8000"

  web:
    build:
      context: apps/web
      dockerfile: Dockerfile.prod
    environment:
      NEXT_PUBLIC_API_URL: http://api:8000
    depends_on:
      - api
    ports:
      - "3000:3000"

volumes:
  pgdata:
```
</action>
<acceptance_criteria>
- `docker-compose.prod.yml` exists at repo root
- Contains services: db, redis, api, web
- db and redis have healthchecks
- api depends_on db and redis with `condition: service_healthy`
- api uses env vars with `DIMED_` prefix matching Settings class
- api environment includes `DIMED_CORS_ORIGINS`
- web environment sets `NEXT_PUBLIC_API_URL`
- Uses named volume `pgdata` for persistence
</acceptance_criteria>
</task>
