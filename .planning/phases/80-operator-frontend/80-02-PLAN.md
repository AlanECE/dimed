### Update middleware for role-based redirect

<read_first>
- apps/web/middleware.ts (current implementation)
</read_first>

<action>
Update `apps/web/middleware.ts`:

The middleware cannot decode JWT (httpOnly cookie, server-side only). But we can use a simple approach:

1. Keep current behavior: no token → redirect /login, token on /login → redirect away
2. For the "redirect away from /login" case, redirect to `/` (root page)
3. Update `apps/web/app/page.tsx` to check user role and redirect accordingly:
   ```typescript
   "use client"
   import { useAuth } from "@/lib/auth"
   import { useRouter } from "next/navigation"
   import { useEffect } from "react"

   export default function Home() {
     const { user, loading } = useAuth()
     const router = useRouter()

     useEffect(() => {
       if (loading) return
       if (!user) { router.push("/login"); return }
       if (user.role === "operatrice" || user.role === "admin") {
         router.push("/dashboard")
       } else {
         router.push("/catalogue")
       }
     }, [user, loading, router])

     return null // loading state handled by layout
   }
   ```

4. Create placeholder pages for operator routes:
   - `apps/web/app/(authenticated)/dashboard/page.tsx` — "Dashboard" heading
   - `apps/web/app/(authenticated)/dashboard/commandes/[id]/page.tsx` — placeholder
   - `apps/web/app/(authenticated)/dashboard/camions/page.tsx` — placeholder
   - `apps/web/app/(authenticated)/dashboard/routes/page.tsx` — placeholder
</action>

<acceptance_criteria>

- middleware.ts redirects from /login to / (root handles role routing)

- `pnpm --filter @dimed/web typecheck` exits 0
