<action>
Create `apps/web/hooks/use-orders.ts`:

```typescript
"use client"

type UseOrdersParams = {
  statut?: string
  dateFrom?: string  // YYYY-MM-DD
  dateTo?: string    // YYYY-MM-DD
  limit?: number
  offset?: number
}

type UseOrdersResult = {
  orders: OrderResponse[]
  total: number
  loading: boolean
  error: string | null
  refetch: () => void
}
```

Implementation:
- `useState` for orders, total, loading, error
- `useEffect` triggered by all params changes
- Call `fetchApi<{commandes: OrderResponse[], total: number}>("/commandes", { params: { statut, date_from: dateFrom, date_to: dateTo, limit, offset } })`
- `refetch()`: re-run the fetch with current params
- Default: limit=20, offset=0
</action>
