# Plan 02: Catalogue + Cart — browse, search, filter, order

## Goal
Pharmacist can browse the medication catalog with live search and filters, add items to a cart sidebar, adjust quantities, and validate an order with a confirmation step.

## Tasks

<task id="02.1">
### Create cart context and state management

<read_first>
- apps/web/lib/types.ts (MedicamentResponse type)
- apps/web/lib/api.ts (fetchApi for order creation)
- .planning/phases/70-pharmacist-frontend/70-CONTEXT.md (Panier & commande decisions)
</read_first>

<action>
Create `apps/web/lib/cart.tsx`:

```typescript
"use client"

type CartItem = {
  medicament: MedicamentResponse
  qte: number
}

type CartContextValue = {
  items: CartItem[]
  addItem: (medicament: MedicamentResponse) => void
  updateQte: (medicamentId: string, qte: number) => void
  removeItem: (medicamentId: string) => void
  clearCart: () => void
  total: number
  itemCount: number
}
```

Implementation:
- `CartProvider` with `useState<CartItem[]>([])`
- `addItem`: if exists, increment qte by 1; else add with qte=1
- `updateQte`: set qte; if qte <= 0, remove item
- `removeItem`: filter out by medicament.id
- `clearCart`: set to []
- `total`: computed from `items.reduce((sum, i) => sum + i.medicament.ppa * i.qte, 0)`
- `itemCount`: computed from `items.reduce((sum, i) => sum + i.qte, 0)`
- Wrap with `CartProvider` in `apps/web/app/(authenticated)/layout.tsx`
</action>

<acceptance_criteria>
- apps/web/lib/cart.tsx exports `CartProvider`, `useCart`
- CartProvider manages items array with addItem, updateQte, removeItem, clearCart
- total computed as sum of (ppa * qte)
- itemCount computed as sum of qte
- `pnpm --filter @dimed/web typecheck` exits 0
</acceptance_criteria>
</task>

<action>
Create `apps/web/hooks/use-medications.ts`:

```typescript
"use client"

type UseMedicationsParams = {
  search?: string
  limit?: number
  offset?: number
}

type UseMedicationsResult = {
  medications: MedicamentResponse[]
  total: number
  loading: boolean
  error: string | null
}
```

Implementation:
- `useState` for medications, total, loading, error
- `useEffect` triggered by search/limit/offset changes
- Debounce search input: 300ms delay before API call
- Call `fetchApi<{medicaments: MedicamentResponse[], total: number}>("/medicaments", { params: { search, limit, offset } })`
- Handle errors: set error message, clear medications
- Initial load with no search, limit=20, offset=0
</action>
