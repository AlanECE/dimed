# Plan 01: Monorepo Structure & Package Managers

## Goal
Set up the Turborepo monorepo with pnpm workspaces, Next.js web app scaffold, and shared packages.

## Tasks

<task id="01.1">
<title>Initialize pnpm workspace root</title>
<read_first>
- (none — greenfield)
</read_first>
<action>
Create root `package.json`:
```json
{
  "name": "dimed",
  "private": true,
  "scripts": {
    "dev": "turbo dev",
    "build": "turbo build",
    "lint": "turbo lint",
    "typecheck": "turbo typecheck",
    "format": "biome check --write ."
  },
  "devDependencies": {
    "@biomejs/biome": "^1.9",
    "turbo": "^2.3",
    "lefthook": "^1.9"
  },
  "packageManager": "pnpm@9.15.0"
}
```

Create `pnpm-workspace.yaml`:
```yaml
packages:
  - "apps/web"
  - "packages/shared-types"
  - "packages/ui"
```

Note: apps/api, apps/mobile, packages/ocr are Python or not yet active — excluded from pnpm workspace.

Run `pnpm install` to generate lockfile.
</action>
<acceptance_criteria>
- `package.json` contains `"name": "dimed"`
- `package.json` contains `"packageManager": "pnpm@9.15.0"`
- `pnpm-workspace.yaml` contains `apps/web`
- `pnpm-workspace.yaml` contains `packages/shared-types`
- `pnpm-lock.yaml` exists after install
</acceptance_criteria>
</task>

<read_first>
- package.json (created in 01.1)
</read_first>
<action>
Create `turbo.json`:
```json

  "$schema": "https://turbo.build/schema.json",
  "globalDependencies": ["**/.env.*local"],
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**"]

    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {
      "dependsOn": ["^lint"]
    },
    "typecheck": {
      "dependsOn": ["^typecheck"]
    }
  }
}
```
</action>
<acceptance_criteria>

</acceptance_criteria>
</task>

<task id="01.5">
<title>Configure Biome and Lefthook</title>
<read_first>
- package.json (root)
</read_first>
<action>
`biome.json`:
```json
{
  "$schema": "https://biomejs.dev/schemas/1.9.0/schema.json",
  "organizeImports": { "enabled": true },
  "linter": {
    "enabled": true,
    "rules": { "recommended": true }
  },
  "formatter": {
    "enabled": true,
    "indentStyle": "tab",
    "lineWidth": 100
  },
  "files": {
    "ignore": ["node_modules", ".next", "dist", ".turbo"]
  }
}
```

`lefthook.yml`:
```yaml
pre-commit:
  parallel: true
  commands:
    biome:
      glob: "*.{js,jsx,ts,tsx,json}"
      run: pnpm biome check --write {staged_files}
      stage_fixed: true
    ruff-check:
      glob: "*.py"
      run: cd apps/api && uv run ruff check {staged_files}
    ruff-format:
      glob: "*.py"
      run: cd apps/api && uv run ruff format --check {staged_files}
```

`.gitignore` at root:
```
node_modules/
.next/
dist/
.turbo/
__pycache__/
*.pyc
.venv/
.env
.env.local
*.egg-info/
```

Run `pnpm lefthook install` to set up git hooks.
</action>
<acceptance_criteria>
- `biome.json` contains `"$schema": "https://biomejs.dev/schemas/`
- `lefthook.yml` contains `pre-commit`
- `lefthook.yml` contains `ruff-check`
- `.gitignore` contains `node_modules/`
- `.gitignore` contains `__pycache__/`
</acceptance_criteria>
</task>
